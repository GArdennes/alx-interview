## Problem description
The question asks us to find the ugly numbers by index. An ugly number is a number that can be divided only by the prime factors 2, 3, and 5 without leaving a remainder.

Although 1 lacks any prime factors. It is considered an ugly number because it doesn't violate the rule that ugly number can only have prime factors of 2, 3, or 5. It meets the condition because 1 can be expressed as 2<sup>0</sup> x 3<sup>0</sup> x 5<sup>0</sup>.

## Dynamic programming approach
The dynamic programming approach to finding ugly numbers is based on an idea: every ugly number, except for 1, is generated by multiplying a smaller ugly number by either 2, 3 or 5. This insight allows us to systematically generate ugly numbers in order.

Starting with 1, the smallest ugly number. To find the next ugly number, we have three options: 1 x 2, 1 x 3, and 1 x 5. The smallest 1 x 2 = 2, becomes the second ugly number. For the third ugly number, we again have three choices: the next multiple of 2 (2 x 2 = 4), and the unused multiples of 3 and 5 from before (1 x 3 = 3 and 1 x 5 = 5). We select the smallest of these which is 3 and continue the process.
